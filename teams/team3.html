Team 03

Smart Waste Management

Project Overview

Description

Develop a sensor-based system that monitors waste bin levels across the city and optimizes collection routes using real-time data analytics and AI-based predictions.

Expected Output

A working prototype with IoT sensor simulation, a web dashboard for city operators, and route optimization algorithm results.
