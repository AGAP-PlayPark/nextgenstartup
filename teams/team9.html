Team 09

A fire and security surveillance system based on Ros

Project Overview

Description

This project develops a mobile robot for fire detection and security surveillance in industrial environments using the ROS communication framework. The system integrates smoke, temperature, flame, and PIR sensors to enable early detection of fire hazards and human motion. Sensor data are transmitted in real time through ROS inter-node communication, while the robot autonomously patrols indoor spaces. Detected events are immediately delivered to users via wireless communication. The project demonstrates the effectiveness of ROS-based modular architectures for disaster response and security monitoring applications.

Main Goals and Objectives

The goal of this project is to develop a ROS-based mobile robot that can autonomously detect fire hazards and human motion through integrated multi-sensor data and real-time communication.

Expected Output

The expected outcome is a mobile surveillance robot prototype with validated fire and intrusion detection capabilities, accompanied by performance evaluation results and system documentation.
