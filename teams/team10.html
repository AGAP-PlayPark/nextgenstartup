Team 10

Autonomous Vehicle Perception and Control Using Camera and LiDAR

Project Overview

Description

This project aims to design and implement an autonomous driving system using a scale-model vehicle operating on an indoor test track. The system employs camera and LiDAR sensors to perceive the environment and performs key autonomous driving tasks, including lane keeping, obstacle avoidance (static and dynamic), traffic signal recognition, and parking. Reliable lane-following is emphasized as the core capability, serving as a foundation for more advanced autonomous behaviors. The project is implemented using the ROS framework to provide hands-on experience with real-world autonomous vehicle technologies.

Main Goals and Objectives

The goal of this project is to design and implement a scale-model autonomous driving system using camera and LiDAR sensors within the ROS framework, focusing on reliable lane following and basic autonomous driving functions.

Expected Output

The expected outcome is a functional autonomous model vehicle capable of lane keeping, obstacle avoidance, and parking, along with experimental results and technical reports demonstrating system performance.
