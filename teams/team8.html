Team 08

Smart Local Traffic Light Management System

Project Overview

Description

This project proposes a system (SLTLMS) to address the problem of traffic signals going dark during power outages in urban areas like Bellevue, WA. This "all-stop" mode causes congestion, confusion, and increased accident risk. The goal is to allow intersections to maintain limited, safe operation using battery/solar backup and AI-driven local logic.

Main Goals and Objectives

Objectives include designing a microcontroller-based local controller, developing a hybrid power management module, implementing intelligent failover logic, creating a monitoring dashboard, and simulating the deployment.

Expected Output

A prototype smart controller, a backup power management module, a web dashboard for monitoring, an AI/logic engine, and a simulation report.
